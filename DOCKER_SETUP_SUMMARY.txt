QUICKEST WAY TO START
================================================================================

Windows PowerShell:
  1. Install Docker: https://www.docker.com/products/docker-desktop
  2. Run: docker-compose up -d
  3. Access: http://localhost:7474
  4. Stop: docker-compose down

DATA PERSISTENCE

Your data is ALWAYS saved, even if container deleted:

  ✓ isekai_world.json   → World settings
  ✓ model/              → AI model files
  ✓ profile/            → User/AI profiles

    - ./model:/app/model
    - ./ingatan_shiro.json:/app/ingatan_shiro.json
    - ./isekai_world.json:/app/isekai_world.json
    - ./profile:/app/profile
    - ./.cache:/app/.cache

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Docker is not recognized"
  → Restart PowerShell or computer after Docker install

Problem: "Address already in use :7474"
  → Change port in docker-compose.yml:
    ports:
      - "8080:7474"  # Use 8080 instead

Problem: "Container keeps exiting"
  → Check logs: docker-compose logs shiro

Problem: "Model files not found"
  → Make sure model files exist: ls model\

Problem: "Memory not persisting"
  → Check volume paths in docker-compose.yml match your PC

SWITCHING BETWEEN METHODS
================================================================================

Docker → PowerShell:
  docker-compose down
  venv\Scripts\Activate
  python web.py
  (Data persists!)

PowerShell → Docker:
  Ctrl+C
  docker-compose up -d
  (Data persists!)

You can switch freely - data is saved either way!

ADVANCED DOCKER COMMANDS
================================================================================

Check running containers:
  docker ps

View logs in real-time:
  docker-compose logs -f

Enter container shell:
  docker exec -it shiro-llma bash

Copy file from container:
  docker cp shiro-llma:/app/ingatan_shiro.json ./

Check resource usage:
  docker stats shiro-llma

Rebuild after code changes:
  docker-compose up --build -d

Fresh start (remove all):
  docker-compose down -v
  docker-compose up -d
