STEP 1: Install Docker (One-Time Only)
  Download: https://www.docker.com/products/docker-desktop
  Install and restart your computer

STEP 2: Start SHIRO
  Option A (Simplest - PowerShell):

    .\run-docker.ps1

STEP 3: Access SHIRO
  Open browser: http://localhost:7474

  (Or: .\run-docker.ps1 stop)

================================================================================
                          WHAT DOCKER DOES
================================================================================

Docker automatically:
  1. Creates isolated Python 3.11 environment
  2. Installs all dependencies (llama-cpp-python, Flask, etc)
  3. Copies your code into container
  4. Starts web.py service
  5. Makes it accessible at http://localhost:7474
  6. Auto-restarts if service crashes
  7. Persists data in volumes (ingatan_shiro.json, profiles, etc)

All in one command: docker-compose up -d

================================================================================
                        DATA PERSISTENCE

All your data is ALWAYS saved, even if container is deleted:
  ✓ ingatan_shiro.json  - Conversations & memory
  ✓ isekai_world.json   - World settings
  ✓ model/              - AI model files
  ✓ profile/            - User & AI profiles

These are mapped as volumes in docker-compose.yml

================================================================================
                      TRADITIONAL STILL WORKS
================================================================================

You can still use PowerShell if you prefer:
  venv\Scripts\Activate
  python web.py

Both work! Data persists either way. You can switch freely!

Switch from traditional to Docker:
  1. Ctrl+C (stop PowerShell version)
  2. docker-compose up -d (start Docker version)
  3. Done! Data is already there

Switch from Docker to traditional:
  1. docker-compose down
  2. venv\Scripts\Activate
  3. python web.py
  4. Done! Data is already there

================================================================================
                        TROUBLESHOOTING
================================================================================

"Docker is not recognized"
  → Restart PowerShell after Docker install

"Address already in use :7474"
  → Change port in docker-compose.yml:
    ports:
      - "8080:7474"

"Container keeps exiting"
  → Check logs: docker-compose logs shiro

"Model not loading"
  → Verify model files exist: dir model\
