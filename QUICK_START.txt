OPTION 1: DOCKER (Recommended)
═══════════════════════════════════════════════════════════════════════════════

Install Docker (one-time only):
  👉 https://www.docker.com/products/docker-desktop

Run SHIRO:
  👉 docker-compose up -d

Access:
  👉 http://localhost:7474

Stop:
  👉 docker-compose down

Restart:
  👉 docker-compose restart

That's it! ✨

═══════════════════════════════════════════════════════════════════════════════

OPTION 2: POWERSHELL (Traditional)
═══════════════════════════════════════════════════════════════════════════════

Open PowerShell and run:
  👉 venv\Scripts\Activate
  👉 python web.py

Access:
  👉 http://localhost:7474

Stop:
  👉 Ctrl+C

═══════════════════════════════════════════════════════════════════════════════

HELPER SCRIPTS (Makes it even easier!)
═══════════════════════════════════════════════════════════════════════════════

Windows PowerShell:
  .\run-docker.ps1              # Start
  .\run-docker.ps1 logs         # View logs
  .\run-docker.ps1 stop         # Stop
  .\run-docker.ps1 status       # Show status
  .\run-docker.ps1 restart      # Restart

Linux/Mac Bash:
  ./run-docker.sh               # Start
  ./run-docker.sh logs          # View logs
  ./run-docker.sh stop          # Stop
  ./run-docker.sh status        # Show status
  ./run-docker.sh restart       # Restart
