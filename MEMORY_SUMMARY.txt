SHIRO MEMORY CAPACITY & HALLUCINATION ANALYSIS
================================================================================

CURRENT LIMITS:
  • Storage: 25 messages max
  • Context loaded: 8 messages (reduced from 15 to prevent hallucination)
  • Model context window: 4096 tokens
  • Response budget: 800 tokens
  • Available for context: ~2896 tokens

CONVERSATION CAPACITY:
  • Typical conversation: 150-200 tokens per exchange
  • With 2896 tokens: Can handle ~14-19 exchanges
  • In practice: ~10-15 full conversations
  ⚠️  After that, hallucination risk increases

WHY HALLUCINATION HAPPENS:
  1. Context window fills up (4096 tokens is small)
  2. Old information mixes with new information
  3. Model gets confused between topics
  4. Token budget exhausted, quality drops

QUICK FIX APPLIED:
  ✅ Reduced get_memory_context(limit) from 15 → 8
     - Saves ~700 tokens per request
     - Fewer conflicts in context
     - Should extend usable conversations from 10 → 15+

RECOMMENDATIONS BY USE CASE:

  For casual conversations:
    • Current setting (8 messages) is GOOD
    • Reset every 20-30 exchanges
    • Should work fine

  For longer sessions (want to remember everything):
    • Use memory_optimization.py
    • Compress old messages into facts every 20 messages
    • Keeps knowledge while saving tokens
    • Requires code changes

  For maximum capacity:
    • Need bigger model with larger context
    • Or use different quantization (more GPU memory)
    • 8K-32K context models available
